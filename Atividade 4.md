## Processo 1  Registro de pedidos

### Requisito 1

**O sistema deve permitir que o vendedor registre um pedido informando os produtos, quantidades e dados do cliente.**

**Fonte 1.** Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.\
**Fonte 2.** Procedimento atual de registro de vendas. Fonte não humana, categoria documentação.

### Requisito 2

**O sistema deve calcular automaticamente o valor total do pedido com base nos produtos e suas respectivas quantidades.**

**Fonte 1.** Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.\
**Fonte 2.** Política comercial de preços e cálculos de venda. Fonte não humana, categoria documentação.

### Requisito 3

**O sistema deve registrar a forma de pagamento escolhida pelo cliente no momento da venda.**

**Fonte 1.** Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.\
**Fonte 2.** Política comercial sobre formas de pagamento aceitas. Fonte não humana, categoria documentação.

## Processo 2  Cadastro e remoção de produtos

### Requisito 4

**O sistema deve permitir que o administrador cadastre um produto informando nome, descrição, preço e quantidade inicial.**

**Fonte 1.** Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.\
**Fonte 2.** Catálogo atual de produtos da empresa. Fonte não humana, categoria documentação.

### Requisito 5

**Fonte 1.** Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.\
**Fonte 2.** Procedimento interno de manutenção do cadastro de produtos. Fonte não humana, categoria documentação.

### Requisito 6

**O sistema deve permitir que o administrador remova um produto que não seja mais comercializado.**

**Fonte 1.** Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.\
**Fonte 2.** Política interna de produtos comercializados. Fonte não humana, categoria documentação.

## Processo 3  Controle de estoque

### Requisito 7

**O sistema deve permitir que o responsável pelo estoque registre a entrada de produtos e atualize a quantidade disponível.**

**Fonte 1.** Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.\
**Fonte 2.** Notas fiscais e documentos de recebimento de mercadorias. Fonte não humana, categoria documentação.

### Requisito 8

**O sistema deve dar baixa automaticamente na quantidade disponível de um produto após o registro de uma venda.**

**Fonte 1.** Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.\
**Fonte 2.** Processo atual de controle de saída de produtos. Fonte não humana, categoria documentação.

### Requisito 9

**O sistema deve permitir que o responsável pelo estoque consulte a quantidade disponível de cada produto.**

**Fonte 1.** Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.\
**Fonte 2.** Relatórios ou planilhas atualmente utilizados para controle de estoque. Fonte não humana, categoria sistema legado.
